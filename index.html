Installer la mise à jour

  1. Conservez l’application actuelle. Téléchargez le fichier APK depuis le bouton ci-dessus, puis vérifiez-le avec le contrôle de fichier de cette page.
  2. Ouvrez le fichier téléchargé. Si Android le demande, autorisez temporairement l’installation depuis le navigateur ou le gestionnaire de fichiers utilisé.
  3. Choisissez « Mettre à jour ». La version de production se met à jour par-dessus l’ancienne, avec le même certificat de signature. Ne désinstallez pas l’application pour forcer l’installation.

Votre ancienne application ne s’ouvre plus ?

Si elle contacte un ancien serveur inaccessible, ouvrez cette page dans le navigateur de votre téléphone pour télécharger la nouvelle version.

Une mise à jour ne restaure pas à elle seule des données perdues sur un ancien serveur. Si Android indique une incompatibilité de signature ou de package, conservez l’installation et demandez de l’aide.
